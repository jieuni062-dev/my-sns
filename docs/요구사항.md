# 빵지순례 요구사항

## 서비스
- 이름: 빵지순례
- 한 줄 소개: 동네 빵집을 순례하며 남기는 사진 기록
- 주제: 동네 빵집 기록 (사진 피드 SNS)

## 게시물 항목
| 항목 | 설명 |
| --- | --- |
| id | 게시물 고유 번호 |
| author | 작성자 이름 |
| content | 본문 글 |
| images | 사진 주소 목록 (1장 이상) |
| created_at | 작성 시각 |

## 화면
- 피드 화면 하나만 있음
- 게시물 카드가 위에서 아래로 쌓임 (최신 글이 위)
- 카드 구성: 작성자, 사진, 본문, 작성 시각
- 휴대폰 폭(가로 430px 이하) 기준

## 캐러셀 상태
- 사진 1장: 사진만 보여줌. 넘기기 동작과 위치 표시(점) 없음
- 사진 여러 장: 좌우로 넘겨서 봄. 현재 몇 번째 사진인지 점으로 표시

## 무한 스크롤 상태
| 상태 | 보여줄 문구 |
| --- | --- |
| 처음 불러오는 중 | 빵 굽는 중이에요… |
| 더 불러오는 중 | 다음 빵을 꺼내는 중이에요… |
| 더 없음 | 오늘 빵은 모두 나왔어요 |
| 오류 | 빵을 가져오지 못했어요. + [다시 시도] 버튼 |

## 분위기
- 크림색 배경에 갓 구운 빵 같은 갈색 포인트. 포근하고 아늑한 동네 빵집 느낌

## 디자인 규칙
손그림 시안 `prototype/feed-a.html` 에 쓴 값을 그대로 옮긴 것.

### 글꼴
- 기본 글꼴: Pretendard, Apple SD Gothic Neo, Malgun Gothic, system-ui, sans-serif
  - 쓰는 곳: 게시물 본문
- 손글씨 글꼴: Gaegu, Nanum Pen Script, Cafe24 Ssurround, 없으면 기본 글꼴
  - 쓰는 곳: 서비스 이름, 한 줄 소개, 작성자, 작성 시각, 숫자 표시, 더 보기, 상태 문구, 버튼
  - 시안은 글꼴 파일을 불러오지 않음. 기기에 설치돼 있을 때만 손글씨로 보임

- 긴 본문은 3줄까지만 보여주고 "더 보기"로 펼침

### 모서리와 선
- 삐뚤한 모서리 A: `255px 18px 225px 18px / 18px 225px 18px 255px`
  - 쓰는 곳: 카드, 숫자 표시, 다시 시도 버튼
- 삐뚤한 모서리 B: `18px 225px 18px 255px / 255px 18px 225px 18px`
  - 쓰는 곳: 사진, 오류 상자
- 테두리: ink 색 2px 실선 위에 1px 선(투명도 45%)을 살짝 어긋나게 한 번 더 겹침. 선은 필터로 삐뚤빼뚤하게
- 오류 상자 테두리: ink 색 2px 점선 한 겹
- 사진 위치 점: 가로 10px · 세로 9px 의 찌그러진 동그라미, 테두리 1.5px. 현재 사진만 crust 색으로 채움
- 카드 그림자: 오른쪽 5px · 아래 6px, 번짐 없음, butter 색
- 버튼 그림자: 오른쪽 3px · 아래 4px, 번짐 없음, ink 색
- 카드 기울기: 홀수 번째 -0.6도, 짝수 번째 0.5도
- 사진 비율: 1 : 1
- 작성자 그림 크기: 38px
